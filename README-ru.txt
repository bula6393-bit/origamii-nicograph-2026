NICOGRAPH 2026 — редактируемый прототип

Как открыть
1. Распакуй ZIP целиком.
2. В VS Code выбери File → Open Folder и открой распакованную папку.
3. Открой index.html в браузере. Можно открыть файл двойным щелчком.
4. После правок сохрани файл и обнови страницу в браузере.

Где править
index.html   — заголовки, подписи, кнопки и разметка страниц.
visitor.css  — дизайн первого экрана и раскладка на телефоне.
styles.css   — дизайн вкладок, таблицы, диалогов и поиска.
visitor.js   — сравнение Miura и Kresling на первом экране.
app.js       — навигация, сравнение, таблица и поиск.
shapes.js    — отрисовка схематичных моделей.
data.js      — 558 записей, источники и матрица критериев.

Для GitHub Pages помести index.html и все CSS и JS из этой папки
рядом в корень репозитория. Для открытия вкладки сравнения
можно использовать адрес сайта с #compare.
